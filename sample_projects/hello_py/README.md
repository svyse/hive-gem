# Hello Py Project

This project contains a simple Python script (`hello.py`) that greets a user.

## Getting Started

Follow these steps to run the application locally.

### Prerequisites

- Python 3.8+

### 1. Run the Script

Navigate to the project root directory in your terminal and run the script:

```bash
python hello.py
```

The script will prompt you to enter your name, and then it will print a personalized greeting.
